# Atlas 界面重设计文档

## 1. 项目初衷

Atlas 是一个本地运行的 A 股投资研究终端，不是数据导出工具。它应该帮助用户每天回答三个问题：

1. 今天市场是什么状态，我的组合有没有出问题？
2. 哪些研究事项还没完成，下一步该做什么？
3. 单只股票的真实数据、来源和缓存时间是什么，能不能据此做研究判断？

所有展示都必须保持研究终端语义：

- 不执行交易，不生成买卖指令。
- 不把历史缓存、回退数据或旧快照伪装成实时数据。
- 每个数字保留来源和时间。
- 缺失数据明确显示，不估算、不补值。

## 2. 现状诊断

改版前的主要问题：

- 晨报像“长表格堆叠”，用户进入后不知道先看什么。
- 市场概览只有数字，没有涨跌颜色、市场强弱和图表。
- 股票详情显示原始浮点金额、英文状态和原始时间戳。
- 组合页连续 6 张表，风险违规、行业集中度、压力测试全部平铺。
- 每个 dataframe 都带通用工具栏，视觉噪音大于信息价值。
- 页面没有统一的视觉层级，用户必须逐字阅读才知道状态。

第一轮改造已完成：

- 增加统一展示层 `app/dashboard/ui.py`。
- 全局样式、KPI 卡片、涨跌红绿、金额亿/万转换、日期时间可读化。
- 晨报、市场概览、股票详情、组合、选股、Thesis、决策日志加入 KPI 头部。
- 组合页把持仓、风险、集中度、压力测试收进 Tab。

## 3. 设计原则

### 3.1 先结论，后明细

每个页面的第一屏必须给出“最重要的状态”：

- 晨报：待办、风险违规、缺 Thesis、候选数量。
- 市场：指数、涨跌、涨停跌停、成交额。
- 组合：市值、现金、盈亏、风险违规。
- 股票：价格、涨跌幅、行情状态。

明细表只能作为第二层信息。

### 3.2 一眼识别状态

- 上涨/正向：红色系。
- 下跌/负向：绿色系。
- 风险/缺失：黄色或红色标签。
- 正常/已覆盖：绿色标签。
- 历史缓存：始终显示“历史缓存”而不是伪装实时。

### 3.3 人类可读，不露原始格式

- 金额：`37.24 亿`、`1.23 万`，不显示 `3048516243.3100004`。
- 百分比：统一 `+2.36%`。
- 状态：`available` 显示为“可用”。
- 时间：`2026-08-09T08:00:00+00:00` 显示为 `08-09 16:00`。

### 3.4 减少滚动和工具噪音

- 高优先级内容留在首屏。
- 历史记录、复盘表单、版本历史收进 expander 或 Tab。
- 通用表格工具按场景保留，不默认铺满整页。

## 4. 信息架构

导航保持七个页面，不改 API 和数据结构：

1. 晨报：每日决策入口。
2. 市场概览：指数与市场广度。
3. 选股中心：候选与筛选覆盖。
4. 股票详情：单股研究档案。
5. 投资逻辑：Thesis 覆盖与版本历史。
6. 决策日志：历史决策与补录。
7. 组合与风险：持仓、风险预算、压力测试。

## 5. 视觉系统

### 5.1 颜色

- 背景：浅灰 `#f6f8fa`。
- 卡片：白底 + 1px 浅边框 + 8px 圆角。
- 文本：深灰 `#1f2937`，辅助文本 `#6b7280`。
- 上涨：`#c62f4a`。
- 下跌：`#00966b`。
- 警示：`#b76e00`。
- 危险：`#c62f4a`。

不使用渐变光晕、装饰球或营销式大图；终端界面保持克制、信息密集但可扫视。

### 5.2 KPI 卡片

每个 KPI 卡片包含：

- 标签：`待完成行动`、`组合市值`。
- 主值：`42`、`1.64 万`。
- 说明：`完成率 0.0%`、`按当前生效风险预算`。
- 状态色：正常、警示、危险。

### 5.3 图表

- 市场广度：上涨/下跌/平盘/涨停/跌停柱状图。
- 组合行业集中度：按权重的柱状图。
- 行动项趋势：按日期完成数柱状图。
- 图表只使用已验证数据，不绘制预测或估算曲线。

## 6. 页面规格

### 6.1 晨报

内容：

- 顶部一句“今日状态”摘要，由真实数据生成，不写无法验证的结论。
- KPI 卡片：待完成行动、风险违规、缺少 Thesis、候选股票。
- 待完成行动项与优先级。
- 指数 KPI 卡片。
- 今日研究待办与风险变化。
- 本地晨报历史与复盘表单收进“晨报历史”Tab。

### 6.2 市场概览

内容：

- 指数 KPI 卡片：沪深300、创业板指、科创50。
- 市场广度 KPI：上涨、下跌、涨停、跌停、成交额。
- 广度柱状图。
- 来源、时间、历史缓存标记。

### 6.3 选股中心

内容：

- KPI：候选总数、有 PE 覆盖、有 ROE 覆盖。
- 排序选择：默认按股票代码，可切换 PE、ROE、净利润同比。
- 结果表保留每个指标的来源。
- 筛选条件留在侧栏。

### 6.4 股票详情

内容：

- 公司名称与代码标题。
- KPI：最新价、涨跌幅、行情状态。
- 资金流 KPI：主力净流入、流入金额、流出金额。
- 财务指标只读缓存表。
- 最近报告期历史与估值收进 expander。

### 6.5 投资逻辑

内容：

- KPI：持仓数量、待定义、已定义。
- 覆盖状态提醒。
- Thesis 表格。
- 版本历史与新增表单。

### 6.6 决策日志

内容：

- KPI：已迁移、计划记录、导入不完整。
- 决策表格。
- 每条决策的详情、补录历史、补录表单。

### 6.7 组合与风险

内容：

- KPI：组合市值、现金比例、浮动盈亏、风险违规。
- 待完成复盘行动与趋势。
- Tab：持仓、风险预算、行业集中度、压力测试。
- 行业集中度柱状图。

## 7. 数据诚实性规则

- 任何 KPI 都可能因为上游不可用而显示“数据不可用”，不得用 0 掩盖缺失。
- 历史缓存必须与实时数据在视觉上区分。
- 来源路径与快照日期不允许从展示层删除。
- 图表不得在无数据时绘制空趋势线或预测线。

4. 每个页面保留来源、时间、历史缓存标记。
5. 不出现原始浮点金额、英文状态或未格式化时间戳。
