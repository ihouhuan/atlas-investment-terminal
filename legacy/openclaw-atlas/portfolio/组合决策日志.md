# Investment Decision Log · 投资决策记录

> 记录每一笔投资决策的完整逻辑链。
> 每条决策必须有：委员会观点 + 个人判断 + 未来验证时间。
> **不构成对未来的预测**，仅记录当时的思考过程。

---

## 决策记录模板

每条决策应包含：

| 字段 | 说明 |
|------|------|
| 日期 | 决策日期 (YYYY-MM-DD) |
| 股票 | TICKER |
| 委员会结论 | Bull / Bear / Risk 综合 |
| Bull 观点 | 简述上行逻辑 |
| Bear 观点 | 简述下行风险 |
| Risk 观点 | 风险等级 + 关键监控指标 |
| 最终决定 | 行动（如：建仓 X% / 观望 / 加仓 / 减仓 / 清仓） |
| 未来验证时间 | 何时 review 这个决策是否正确 |

## 纪律

1. **决策必须有数据**：禁止"凭感觉"建仓
2. **必须三视角齐全**：Bull / Bear / Risk 缺一不可
3. **必须有 review 时间**：每个决策都要有验证锚点
4. **诚实记录结果**：错了就写错了，不掩饰
