## 自定义情景

通过 CLI 传入自定义跌幅：

```bash
python3 scenario_engine.py --custom "NVDA:-50,MSFT:-30,AAPL:-25"
```

---

## 关键原则

1. **不是预测** — 这些是 Hypothetical，不是预报
2. **是风险评估** — 评估"如果...怎么办"
3. **检查脆弱性** — 找出组合中的脆弱点
4. **辅助决策** — 帮助调整结构，不强制行动
