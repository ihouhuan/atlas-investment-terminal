# Decision Journal · 决策日志

> Atlas 投资办公室 — 记录**每一次**投资决策的完整逻辑。
> 每条决策必须经过 10 字段完整记录 → 让假设可被验证。

---

## 使用规范

### 强制记录

所有以下动作必须记录：
- ✅ 建仓（首次买入）
- ✅ 加仓 / 减仓（持仓变动 > 20%）
- ✅ 清仓（卖出全部）
- ✅ 重新评估现有持仓（重大 thesis 变更）

### 时间要求

- **决策当天**记录（不允许事后补登）
- 价格、仓位数据从 yfinance 实时拉取

### 字段填写要求

| 字段 | 要求 |
|------|------|
| 日期 | 决策日期 YYYY-MM-DD |
| 股票 | TICKER（如 AAPL）|
| 动作 | 建仓 / 加仓 / 减仓 / 清仓 / 重新评估 |
| 价格 | 决策时价格（USD/HKD/CNY）|
| 仓位 | 占总资产比例 % |
| 投资理由 | 1-3 句话 |
| 核心假设 | **最重要** — 1 句话，可证伪 |
| 验证指标 | 2-5 个可量化指标 |
| 最大风险 | 1 句话，最坏情况 |
| 失败条件 | 触发清仓的具体条件 |
| 预期时间 | 持有周期（如 1 年 / 长期）|
