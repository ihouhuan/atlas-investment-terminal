---

## 警告来源说明

```python
# urllib3/__init__.py:35
NotOpenSSLWarning: urllib3 v2 only supports OpenSSL 1.1.1+, 
currently the 'ssl' module is compiled with 'LibreSSL 2.8.3'
```

这是 urllib3 v2 的**预检性警告**，目的是提示用户某些高级特性可能不可用。但在 macOS + LibreSSL 这个组合下，**基本 HTTPS 功能完全可用**。

---

## 解决方案评估

| 方案 | 操作 | 评估 |
|------|------|------|
| A. 忽略警告 | `warnings.filterwarnings('ignore')` | ✅ **推荐**：已采用，实际无影响 |
| B. 降级 urllib3 | `pip install 'urllib3<2'` | 可消除警告，但失去 v2 改进 |
| C. 安装 pyopenssl | `pip install pyopenssl` | 不一定解决问题 |
| D. 升级 Python | 使用 pyenv 装 3.11+ | 工作量大，无必要 |

**当前选择**：**方案 A（忽略警告）**，理由：
1. 实际功能完整可用（已验证）
2. 最小侵入性
3. 已在所有脚本中应用 `warnings.filterwarnings('ignore')`

---

## 推荐配置

在所有投资相关 Python 脚本开头加入：

```python
import warnings
warnings.filterwarnings('ignore')
```

或使用环境变量：

```bash
export PYTHONWARNINGS="ignore::urllib3.exceptions.NotOpenSSLWarning"
```
