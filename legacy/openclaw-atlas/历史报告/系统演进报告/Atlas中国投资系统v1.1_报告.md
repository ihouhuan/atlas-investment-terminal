## 三、模块详情

### 3.1 Morning Brief v1.1

**文件**：`china_morning_brief.py` (390 行)

**A 股 Morning Brief 结构**：

1. **隔夜全球**（美股情绪参考，yfinance）
2. **A 股市场状态**（沪深 300 / 中证 500 / 创业板 / 科创 50）
3. **热点板块**（资金流向 — 占位，待专业接口）
4. **资金面**（北向 / 融资融券 / 成交额 — 占位）
5. **自选股**（实时行情 + 异常信号）
6. **风险概览**（仓位规则 + 触发器）
7. **今日观察**（重点关注 + 操作纪律）

**数据源**：
- 腾讯 qt.gtimg.cn（A 股指数 + 股票）
- yfinance（美股情绪）
- 占位字段（北向 / 资金流）

**输出**：`investment/china_market/reports/china_morning_brief_{DATE}.md`

### 3.2 Stock Research v1.1

**文件**：`china_stock_research.py` (480 行)

**A 股研究模板结构**：

1. **基本信息**（名称/代码/交易所/行情时间）
2. **实时行情**（价格/涨跌/换手/市值/PE/PB）
3. **估值水平**（PE/PB + 历史分位估算）
4. **财务质量**（占位，待 Tushare）
5. **资金面**（占位，待专业接口）
6. **风险评估**（PE/换手/市值/行业）
7. **Atlas 综合判断**（动态评分 + 风险等级）

**输出**：`investment/china_market/reports/research/{TICKER}_{DATE}.md`

### 3.3 Valuation Engine v1.1

**文件**：`china_valuation_engine.py` (440 行)

**A 股估值方法**：

1. **基础估值**：PE / PB（实时）
2. **PE 历史分位估算**：基于行业平均 PE × [0.5, 1.8] 区间
3. **跨维度评分**：PE + 波动率 + 稳定性 + 增长 + 行业周期（5 维度加权）
4. **动态评级**：自动输出 LOW/MEDIUM/HIGH
5. **行业对比**：行业平均 PE 对比

**待接入**（Tushare）：PS / PEG / 股息率 / DCF / 真实历史分位

**输出**：`investment/china_market/reports/valuation/{TICKER}_valuation_{DATE}.md`

### 3.4 Investment Committee v1.1（五角色）

**文件**：`china_investment_committee.py` (480 行)

**五角色**：

| 角色 | 关注 |
|------|------|
| **多头分析师** (Bull Analyst) | 基本面 / 估值 / 增长 |
| **资金流分析师** (Capital Flow Analyst) | 北向 / 主力 / 散户 / 换手 |
| **政策分析师** (Policy Analyst) | 行业政策 / 监管 / 战略方向 |
| **空头分析师** (Bear Analyst) | 估值风险 / 增长放缓 / 行业逆风 |
| **风险分析师** (Risk Analyst) | 仓位规则 / 流动性 / 波动率 / 评级 |

**综合逻辑**：投票统计（多头 vs 空头）+ 风险等级 → 仓位建议

**输出**：`investment/china_market/reports/committee/{TICKER}_committee_{DATE}.md`
