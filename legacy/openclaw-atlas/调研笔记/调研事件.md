# 研究事件台账 · Events Log

> 记录影响投资判断的重大事件：财报、政策、产品发布、管理层变化、行业新闻等。
> 按时间倒序排列（最新事件在最上方）。

---

## 事件记录模板

每条事件应包含：

| 字段 | 说明 |
|------|------|
| 日期 | 事件发生日期 (YYYY-MM-DD) |
| 股票 | 涉及股票代码 |
| 事件 | 简短描述 |
| 来源 | 信息出处（公告 / 媒体 / 内部研究） |
| 事件影响 | 对短期股价的可能影响（利好/利空/中性） |
| 长期影响 | 对基本面/估值的长期影响 |
| 备注 | 其他说明 |

## 事件类型分类

| 类型 | 说明 | 关注频率 |
|------|------|----------|
| 财报 | 季度财报、年报 | 季度 |
| 政策 | 监管、行业政策 | 不定期 |
| 产品 | 新产品发布、技术更新 | 不定期 |
| 管理层 | CEO/CFO 变更、大股东动作 | 不定期 |
| 并购 | 收购、合并、分拆 | 不定期 |
| 行业 | 行业重大变化 | 不定期 |
| 宏观 | 利率、汇率、地缘 | 持续 |
