## 🔧 工具入口

### atlas_py v2.0 子命令

```bash
# A 股 6 大功能
atlas_py committee <symbol>   # 投委会报告（5 角色投票）
atlas_py valuation <symbol>    # 估值报告（动态评级）
atlas_py research <symbol>     # 个股深度研究
atlas_py morning               # A 股早盘简报
atlas_py market <symbols...>   # 拉行情数据
atlas_py cross                 # 跨市场观察简报

# 压力测试 4 个工具
atlas_py 投资/scripts/scenario_engine.py --scenario bear_market
atlas_py 投资/scripts/drawdown_analyzer.py AAPL MSFT
atlas_py 投资/scripts/risk_cluster.py AAPL MSFT
atlas_py 投资/scripts/recovery_analyzer.py AAPL

# 系统状态
atlas_py 投资/scripts/market_regime.py    # 当前市场状态
atlas_py 投资/scripts/thesis_monitor.py   # Thesis 监控
```

### 直接调用（向后兼容）

```bash
# 直接调用任何 Python 脚本
atlas_py 投资/china_market/scripts/china_market_data.py 601899.SH
```

报告生成后**自动**出现在中文目录。

## 📌 命名规则

- **目录**：`A股分析/报告类型/` 全中文
- **文件名**：`股票中文名_报告类型_日期.md`
  - `紫金矿业_投委会报告_2026-08-08.md`
  - `A股早盘简报_2026-08-08.md`
  - `回撤分析_2026-08-08.md`
- **代码模块**：保留英文（Python import 友好）
  - `core/`, `china_market/scripts/`, `cross_market/scripts/`
  - `scripts/atlas_py` (wrapper)
- **路径常量**：见 `核心代码/core/paths.py`
